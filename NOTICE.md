This standalone implementation generalizes research utilities authored for the maintainer's own application. The public API has been independently hardened; it is not a drop-in replacement for that application's internal modules. No private datasets, account records, source transcripts, execution adapters, credentials, or repository history are included. All examples and test fixtures are synthetic.

Algorithms implement conventional statistical or explicitly documented analytical definitions. No third-party source code is bundled. TypeScript is a development-only tool with its own license in its distribution; this package has no runtime dependencies.

This is research software, not financial advice, an execution system, or a guarantee of predictive performance.
